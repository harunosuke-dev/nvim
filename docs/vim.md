## いちばん大事な考え方

Vim のキーは**英語の単語の頭文字**でできている。そして**文法がある**。

```
d  w        →  delete word          単語を消す
c  i  "     →  change inside "      引用符の中を書き換える
y  a  f     →  yank around function 関数を丸ごとコピー
```

**動詞 + 範囲**という並びになっている。動詞と範囲をそれぞれ覚えれば、掛け算で操作が増える。20個覚えれば数百通りの操作ができる。これが「記号を覚える」のとの決定的な違い。

## モード

Vim には状態がある。**今どのモードにいるかで、同じキーの意味が変わる。**

| モード | 入り方 | 何をする場所か |
|---|---|---|
| **ノーマル** | `Esc` | **既定の状態。** 移動と編集の指示を出す |
| **挿入** | `i` `a` `o` など | 文字を打ち込む |
| **ビジュアル** | `v` `V` `Ctrl+v` | 範囲を選ぶ |
| **コマンドライン** | `:` `/` `?` | コマンドを打つ、検索する |

**ノーマルモードが家。** 迷ったら `Esc` を押して戻る。他のエディタは「常に挿入モード」だと考えると分かりやすい。

### 挿入モードへの入り方は使い分ける

| キー | 由来 | どこから打ち始めるか |
|---|---|---|
| `i` | **i**nsert | カーソルの**手前** |
| `a` | **a**ppend | カーソルの**次** |
| `I` | | 行の**先頭**（インデントの後） |
| `A` | | 行の**末尾** |
| `o` | **o**pen | **下**に新しい行を作る |
| `O` | | **上**に新しい行を作る |

行末に `;` を足したいなら `A` で一発。いちいち `$` で移動してから `a` を押す必要はない。

## 移動

**移動（motion）は動詞と同じくらい重要。** Vim の操作は次の形で組み立てる。

```
[回数] 動詞 [回数] 移動
  3      d          w      →  3語ぶん消す（d3w でも 3dw でも同じ）
         c          t)     →  ) の手前まで書き換える
  5      -          j      →  5行下へ（動詞なしなら移動だけ）
```

**動詞を覚えても移動を知らなければ範囲を指定できない。** 逆に移動さえ増やせば、既に知っている動詞すべてに掛け算で効く。`dw` を知っていれば `d}`（段落の終わりまで消す）も `dt,`（カンマの手前まで消す）も自然に出てくる。

**回数はほとんどの移動に付けられる。** `3w`（3語先へ）、`5j`（5行下へ）、`2f,`（2つ目のカンマへ）。

### 基本

| キー | 由来 | 動作 |
|---|---|---|
| `h` `j` `k` `l` | | 左 下 上 右 |
| `w` | **w**ord | 次の語の先頭へ |
| `e` | **e**nd | 語の末尾へ |
| `b` | **b**ack | 前の語の先頭へ |
| `0` | | 行の先頭 |
| `^` | | 行の最初の文字（インデントを除く） |
| `$` | | 行の末尾 |
| `gg` | **g**o | ファイルの先頭 |
| `G` | | ファイルの末尾 |
| `{` `}` | | 段落・ブロック単位で上下 |
| `Ctrl+u` `Ctrl+d` | **u**p / **d**own | 半画面スクロール |

**この設定では `w` `e` `b` が camelCase の区切りで止まる。** `getUserName` を `get` / `User` / `Name` の3語として扱うので、長い識別子の一部だけを直せる。

### 行内をピンポイントで

| キー | 由来 | 動作 |
|---|---|---|
| `f` + 文字 | **f**ind | その文字へ飛ぶ |
| `F` + 文字 | | 逆方向へ |
| `t` + 文字 | **t**ill | その文字の**手前**まで |
| `T` + 文字 | | 逆方向 |
| `;` `,` | | 直前の `f`/`t` を繰り返す / 逆方向 |

`f(` で括弧へ、`t,` でカンマの手前へ。**`d` や `c` と組み合わせる**のが本領。

```
dt,     カンマの手前まで消す
ct)     ) の手前まで書き換える
yf"     " まで（含めて）コピー
d2f,    2つ目のカンマまで消す
```

`;` で繰り返せるので、`f,` を1回打てば以降は `;` だけで次のカンマへ渡れる。**行内の移動はほぼこれで足りる。**

### 括弧・構造をまたぐ

| キー | 動作 |
|---|---|
| `%` | **対応する括弧へ飛ぶ**（`(` ⇄ `)`、`{` ⇄ `}`、開始タグ ⇄ 閉じタグ） |
| `[{` / `]}` | 今いるブロックの開き / 閉じ括弧へ |
| `(` / `)` | 文単位で前後へ |
| `{` / `}` | 段落・空行単位で前後へ |

**`%` は使用頻度が高い。** 長い関数の末尾を見たい時、`{` の上で `%` を押せば一発で対応する `}` へ飛ぶ。`d%` なら括弧ごと消える。

**この設定では構文木を使った移動も入っている。**

| キー | 動作 |
|---|---|
| `]f` / `[f` | 次 / 前の**関数**の先頭へ |
| `]F` / `[F` | 関数の末尾へ |
| `]a` / `[a` | 次 / 前の**引数**へ |
| `]c` / `[c` | 次 / 前の**変更箇所**（git の差分）へ |
| `]d` / `[d` | 次 / 前の**診断**（エラー・警告）へ |
| `]]` / `[[` | 次 / 前の**同じ識別子**へ |

`]` が次、`[` が前。**この対応は Vim 全体で一貫している。**

### 画面の中で動く

| キー | 由来 | 動作 |
|---|---|---|
| `H` | **H**igh | 画面の**最上行**へ |
| `M` | **M**iddle | 画面の**中央**へ |
| `L` | **L**ow | 画面の**最下行**へ |
| `zz` | | **カーソル行を画面の中央**に持ってくる |
| `zt` | **t**op | カーソル行を最上部へ |
| `zb` | **b**ottom | カーソル行を最下部へ |
| `Ctrl+f` / `Ctrl+b` | **f**orward / **b**ack | 1画面ぶん進む / 戻る |

**`zz` は覚えておくと快適。** 検索でジャンプした直後は画面の端に着地しがちなので、`zz` で中央に寄せると前後の文脈が見える。

### 行番号で飛ぶ

| キー | 動作 |
|---|---|
| `42G` または `:42` | 42行目へ |
| `gg` / `G` | ファイルの先頭 / 末尾 |
| `42%` | ファイル全体の42%の位置へ |

エラーメッセージに行番号が出た時は `42G` が速い。**この設定は相対行番号を出している**ので、画面内の移動は `5j` `12k` のように見えている数字をそのまま打てばよい。

### 印を付けて戻る

| キー | 由来 | 動作 |
|---|---|---|
| `ma` | **m**ark | 今の位置に `a` という印を付ける |
| `` `a `` | | 印 `a` の位置へ（桁まで正確に） |
| `'a` | | 印 `a` の行へ |
| `` `` `` | | **直前にいた位置へ**（トグルのように往復できる） |

印は小文字が「そのファイル内」、大文字が「ファイルをまたぐ」。`mA` で印を付ければ、別のファイルからでも `` `A `` で戻れる。

### 検索

| キー | 動作 |
|---|---|
| `/` + 語 | 前方へ検索 |
| `?` + 語 | 後方へ検索 |
| `n` `N` | 次 / 前の一致へ |
| `*` `#` | **カーソル下の単語**を前方 / 後方に検索 |
| `g*` | 同じだが**部分一致**（`foobar` の中の `foo` も拾う） |

`*` は変数名の上で押すだけで使えるので、打ち込む手間がない。

**この設定では `*` と `g*` は動かない。** 標準の `*` は検索語を登録したうえで次の出現へ飛ぶが、それだと置換を始めた時に1つ目が飛ばされる。カーソルはその場に留めてある。

→ 検索してから直す流れは [同じ語をいくつも直す](#同じ語をいくつも直す) に。

### 戻る・進む

| キー | 動作 |
|---|---|
| `Ctrl+o` | **前にいた場所へ戻る**（ブラウザの戻るボタン） |
| `Ctrl+i` | 進む |
| `` `` `` | 直前の位置へ |

定義へジャンプした後、`Ctrl+o` で元の場所へ戻れる。**これを知らないと Vim は使いづらい。**

## 編集

### 動詞

| キー | 由来 | 動作 |
|---|---|---|
| `d` | **d**elete | 消す |
| `c` | **c**hange | 消して挿入モードへ |
| `y` | **y**ank | コピー |
| `p` | **p**ut | 貼り付け（カーソルの後） |
| `P` | | 貼り付け（カーソルの前） |
| `>` `<` | | インデントを増やす / 減らす |
| `=` | | インデントを整える |

**同じキーを2回押すと1行が対象。** `dd` で1行削除、`yy` で1行コピー、`cc` で1行書き換え。

**大文字は「行末まで」。** `D` は行末まで削除、`C` は行末まで書き換え、`Y` は行末までコピー。

### 単発の操作

| キー | 由来 | 動作 |
|---|---|---|
| `x` | | 1文字消す |
| `r` + 文字 | **r**eplace | 1文字置き換える |
| `u` | **u**ndo | 取り消す |
| `Ctrl+r` | **r**edo | やり直す |
| `.` | | **直前の操作を繰り返す** |
| `J` | **J**oin | 次の行と連結する |

**`.` は Vim でいちばん強力なキー。** 「1箇所直して、次の箇所へ移動して `.`」を繰り返すのが基本の型。`n` で次の検索結果へ飛んで `.` を押す、という組み合わせが効く。

→ この型を使い込む話は [同じ語をいくつも直す](#同じ語をいくつも直す) にまとめてある。

## テキストオブジェクト

**Vim を使う最大の理由がこれ。** 「範囲」を構造で指定できる。

```
d  i  (      delete inside ( )     括弧の中身を消す
c  a  "      change around " "     引用符ごと書き換える
y  i  t      yank inside tag       タグの中身をコピー
```

| 修飾 | 由来 | 意味 |
|---|---|---|
| `i` | **i**nside | 中身だけ |
| `a` | **a**round | 囲みも含めて |

| 対象 | 意味 |
|---|---|
| `w` | 単語 |
| `s` | 文（**s**entence） |
| `p` | 段落（**p**aragraph） |
| `(` `)` `b` | 丸括弧 |
| `{` `}` `B` | 波括弧 |
| `[` `]` | 角括弧 |
| `"` `'` `` ` `` | 引用符 |
| `t` | HTML / JSX のタグ（**t**ag） |

**この設定では構文木を使ったものも追加されている。**

| 対象 | 意味 | 担当 |
|---|---|---|
| `f` | 関数（**f**unction） | treesitter |
| `c` | クラス・コンポーネント（**c**lass） | treesitter |
| `a` | 引数（**a**rgument） | treesitter |

```
vaf   関数を丸ごと選択
dif   関数の中身を消す
cia   引数を書き換える
ci(   括弧の中を書き換える（カーソルが手前にあっても効く）
2i(   2つ外側の括弧の中
```

**`ci(` はカーソルが括弧の中になくても動く。** mini.ai が入っているので、次の括弧を自動で探す。複数行にまたがる文字列でも効く。

## ビジュアルモード

| キー | 動作 |
|---|---|
| `v` | 文字単位で選択 |
| `V` | **行単位**で選択 |
| `Ctrl+v` | **矩形**選択（列を揃えて編集する時） |
| `gv` | **直前の選択範囲を復元** |
| `o` | 選択範囲の**反対側の端**へ移る |

**`o` を知っておくと便利。** 右へ伸ばした後で左も伸ばしたくなったら `o` を押してから `h` や `b` を使う。

選択したら動詞を押すだけ。`vaf` で関数を選んで `d` で消す、`y` でコピーする。

### この設定で追加したもの

| キー | 動作 |
|---|---|
| `J` `K` | **選択行を下 / 上へ移動**（インデントも自動で直る） |
| `<` `>` | インデントを減らす / 増やす（**選択が保たれる**ので連打できる） |

素の Vim では `>` を押すと選択が外れるが、この設定では保たれる。

## 同じ語をいくつも直す

**マルチカーソルの代わり。** Neovim 0.12 にマルチカーソルは無いが、以下で用途のほとんどが片付く。**上に行くほど手軽で、下に行くほど範囲が広い。**

| 方法 | 範囲 | 向いている場面 |
|---|---|---|
| `grn` | プロジェクト全体 | **変数名・関数名**を変える |
| `cgn` + `.` | どこでも | 1つずつ選びながら直す |
| `:s` | このファイル | まとめて、または確認しながら |
| `Ctrl+q` → `:cfdo` | 複数ファイル | 検索結果を一括で |
| `<Space>rr` | プロジェクト全体 | 画面で確認しながら一括で |
| `Ctrl+v` | 同じ列 | 語ではなく**位置**を直す |

### まず `grn` — 名前を変えるなら

対象が**変数名や関数名**なら、文字列の置換ではなく LSP の名前変更を使う。

```
grn 新しい名前 Enter
```

意味を理解した上で変えるので、コメントや文字列の中の同じ綴りを巻き込まない。スコープ違いの同名も間違えない。**これで済むならこれが最善。**

以降は、LSP が効かない場面（設定ファイル、Markdown、コメント、部分一致）の話。

### `cgn` — 1つずつ選びながら直す（VSCode の `Cmd+D` に相当）

**いちばん使う型。** 覚えるのは `cgn` だけ。

```
*                カーソル下の語を検索（この設定では動かない）
cgn 新しい語 Esc   1つ目を直す
n  .             次へ飛んで、同じ変更を繰り返す
```

`gn` は「次の一致を選択する」テキストオブジェクト。`c` と組み合わせて `cgn` で「次の一致を書き換える」になる。カーソルが一致の上にある時は**その一致**が対象。

| 打鍵 | 意味 |
|---|---|
| `n` `.` | 次を直す |
| `n` `n` `.` | 1つ飛ばして次を直す |
| `u` | 直前の1つだけ取り消す |

**`n` と `.` のどちらを押すかをその場で決められる**のが、マルチカーソルより扱いやすい点。画面外の出現にも同じように効く。

`dgn` なら削除、`ygn` ならコピーになる。

**標準の `*` は次の出現へ飛ぶ**ので、そのまま `cgn` すると1つ目が飛ばされる。この設定では `*` と `g*` をその場に留まるようにしてあるため、`N` で戻す必要がない。

`/` で検索した場合はカーソルが一致の上に乗るので、そのまま `cgn` でよい。

### `:s` — このファイルの中をまとめて

```
:%s/古い語/新しい語/g       ファイル全体
:%s/古い語/新しい語/gc      1つずつ確認しながら（y / n / a / q）
:s/古い語/新しい語/g        カーソル行だけ
:'<,'>s/古い語/新しい語/g   選択範囲だけ（ビジュアルモードで : を押すと先頭に入る）
```

`*` で検索してから `:%s//新しい語/g` と**検索語を空にする**と、直前の検索語がそのまま使われる。打ち直さずに済む。

### quickfix — 複数のファイルにまたがって

`<Space>fg`（全文検索）で候補を出し、**`Ctrl+q` で全部を quickfix に送る**。そこから2つの進め方がある。

**まとめて置換する**

```
:cfdo %s/古い語/新しい語/ge | update
```

| 部分 | 意味 |
|---|---|
| `:cfdo` | quickfix に載った**ファイルごと**に実行（`:cdo` は行ごと） |
| `%s/…/…/g` | そのファイル全体を置換 |
| `e` | 一致が無いファイルでエラーを出さない |
| `update` | 変更があった時だけ保存 |

**1つずつ見て回る**

```
]q    次の候補へ      [q  前の候補へ
```

`]q` `[q` は Neovim 0.12 が標準で持つ。`<Space>uq` で一覧を開閉できる。飛んだ先で `cgn` や `.` を使えば、確認しながら直せる。

### `<Space>rr` — 画面で確認しながら一括で

コマンドを打たずに、検索語と置換後を入力欄に書いて結果を見ながら進める。

| キー | 動作 |
|---|---|
| `<Space>rr` | プロジェクト全体を検索・置換 |
| `<Space>rw` | カーソル下の単語を置換（**w**ord） |
| `<Space>rf` | このファイル内を置換（**f**ile） |

`:cfdo` と守備範囲は同じ。**正規表現を試しながら書きたい時**はこちらが楽。

### 矩形選択 — 列がそろっている時

同じ語ではなく**同じ位置**を直す場合はこちら。

```
Ctrl+v      矩形選択を始める
j j j       下へ伸ばす
I           先頭に挿入（A なら末尾に追記）
文字を打つ
Esc         ← ここで全行に反映される
```

`Esc` を押すまで1行目にしか見えないが、離すと全部に入る。

## Neovim 0.12 が標準で持つもの

**プラグインなしで使える。** `g` + `r` が LSP 操作の入り口になっている（`r` は **r**eference の r）。

| キー | 由来 | 動作 |
|---|---|---|
| `grn` | **r**e**n**ame | 名前を変える（プロジェクト全体） |
| `gra` | **a**ction | コードアクション（自動修正の提案） |
| `grr` | **r**eferences | 参照している箇所の一覧 |
| `gri` | **i**mplementation | 実装へジャンプ |
| `grt` | **t**ype | 型定義へジャンプ |
| `gO` | **O**utline | ファイル内のシンボル一覧 |
| `K` | | **カーソル下の情報を表示**（型・ドキュメント） |
| `Ctrl+s`（挿入中） | **s**ignature | 引数の説明を表示 |

| キー | 動作 |
|---|---|
| `]d` `[d` | 次 / 前の**診断**（**d**iagnostic）へ |
| `]q` `[q` | 次 / 前の **quickfix** 項目へ |
| `gc` + 範囲 | **コメントの切り替え**（`gcc` で1行、`gcap` で段落） |

`]` が「次」、`[` が「前」。**この対応は Vim 全体で一貫している。**

## 追加プラグインの使い方

### flash.nvim — 画面内を一足飛びに

| キー | 動作 |
|---|---|
| `Enter` | 画面内の任意の位置へジャンプ |
| `<Space>Enter` | **構文ノード単位で選択を広げる** |
| `r`（オペレータ待ち） | 離れた位置を操作対象にする |

**`Enter` を押してから移動先の文字を2文字打つ**と、候補にラベルが出る。ラベルのキーを押せばそこへ飛ぶ。画面内であれば距離に関係なく2〜3打で届く。

**`<Space>Enter` は構造を選ぶ時に使う。** カーソル位置を含む構文ノード（式 → 文 → ブロック → 関数）すべてにラベルが出るので、欲しい階層のラベルを押す。`vaf` のように名前を知らなくても選べる。

`r` は少し特殊で、`yr` と押すと「離れた場所の単語をコピーして、カーソルは今の位置に残る」という動作になる。

### nvim-surround — 囲みを操作する

**`s` は surround の s。**

| キー | 動作 | 例 |
|---|---|---|
| `ys` + 範囲 + 文字 | 囲む（**y**ou **s**urround） | `ysiw"` → 単語を `"` で囲む |
| `ds` + 文字 | 囲みを外す（**d**elete **s**urround） | `ds"` → `"` を外す |
| `cs` + 旧 + 新 | 囲みを変える（**c**hange **s**urround） | `cs"'` → `"` を `'` に |
| `S`（選択中） | 選択範囲を囲む | `viwS(` |

JSX なら `ysiwt` でタグ名を入力して要素で囲める。

### nvim-spider — camelCase 単位の移動

**覚えるキーはない。** `w` `e` `b` `ge` の挙動が変わるだけ。

```
getUserName  →  w を押すと get → User → Name と渡れる
user_name_id →  同様に3語として扱われる
```

`ciw` で単語を書き換える時も、`User` の部分だけが対象になる。

### mini.ai — 括弧・引用符を賢く

**覚えるキーはない。** 既存の `i(` `a"` などが強くなる。

| 操作 | 素の Vim | この設定 |
|---|---|---|
| `ci(` | カーソルが括弧の中にある時だけ | **手前にあっても次の括弧を探す** |
| `ci"` | 1行の中だけ | **複数行にまたがっても効く** |
| `2i(` | 使えない | **2つ外側の括弧の中** |

### treesj — 1行 ⇄ 複数行

| キー | 動作 |
|---|---|
| `<Space>j` | 切り替え |

`{ a: 1, b: 2 }` にカーソルを置いて押すと各プロパティが1行ずつに開く。もう一度押すと戻る。**構文木を使うのでカンマや括弧の整合が崩れない。** JSX の props を折り返す時にも使える。

### ts-error-translator — TypeScript のエラーを平易に

**操作は不要。** 型エラーが自動で読みやすい文章に置き換わる。

### render-markdown — Markdown を整形表示

**操作は不要。** 見出し・表・コードブロックがその場で整形される。**挿入モードでは素のテキストに戻る**ので編集の邪魔にならない。

### rainbow-delimiters — 括弧の色分け

**操作は不要。** ネストの深さごとに括弧の色が変わる。JSX の入れ子で対応関係を追える。

### 色の可視化

**操作は不要。** `#7d8296` や `rgb(...)` にその色の背景が付く。CSS は LSP、それ以外は nvim-colorizer が担当する。

## 覚える順番

一度に全部は覚えられない。**この順で1つずつ手に馴染ませる**のが早い。

**1週目 — 移動できるようになる**

```
h j k l    w b        gg G
/ で検索   n で次      Ctrl+o で戻る
```

**2週目 — 動詞と範囲を組み合わせる**

```
dd  yy  p       diw  ciw       ci(  ci"
u で取り消す     . で繰り返す
```

**3週目 — 構造で編集する**

```
vaf  dif  cia          <Space>Enter で構造を選ぶ
ysiw"  cs"'  ds"       Enter でジャンプ
```

**4週目 — LSP と検索を使う**

```
grn  gra  K  ]d
<Space>ff  <Space>fg  <Space>gd  <Space>rr
```

## 困った時

| 状況 | 対処 |
|---|---|
| 今どのモードか分からない | `Esc` を2回押す。ノーマルモードに戻る |
| キーを忘れた | `<Space>` を押して待つ。which-key が候補を出す |
| キーを検索したい | `<Space>fk` |
| コマンドの意味を知りたい | `:help ciw` のように引く |
| 操作を間違えた | `u` で取り消す。`Ctrl+r` でやり直す |
| ファイルが壊れた気がする | `:e!` で保存せずに開き直す |

**`:help` は Vim の最大の資産。** `:help text-objects` `:help motion.txt` あたりから読むと体系が掴める。
