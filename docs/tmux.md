# tmux の操作

この Neovim 設定と組み合わせて使う tmux の操作。設定の実体は [dotfiles](https://github.com/Harunosuke-web/dotfiles) の `packages/tmux/` にある。

関連: [ウィンドウ操作（yabai + skhd）](window.md)

**prefix は `Ctrl + b`。** 以下では `C-b` と表記し、`C-b c` は「`Ctrl + b` を押して離してから `c`」を意味する。

---

## 全体像

tmux は3階層で構成される。

```
セッション（プロジェクト単位）
  └─ ウィンドウ（タブのようなもの）
       └─ ペイン（画面分割）
```

この設定ではプロジェクトごとにセッションを作り、その中でウィンドウとペインを使う。

---

## セッション

プロジェクト単位の作業場所。**閉じても残る**ので、後から同じ状態に戻れる。

| キー | 動作 |
|---|---|
| `C-b C-f` | プロジェクトを選んでセッションを作成 / 切り替え |
| `C-b C-s` | セッションを切り替え |
| `C-b C-n` | 名前を指定して新規作成 |
| `C-b C-x` | セッションを削除 |
| `C-b d` / `C-b C-d` | 切り離してシェルに戻る（**セッションは残る**） |

`C-b C-f` を押すと `~/Repos/github.com/Harunosuke-web` などの配下のプロジェクトが一覧で出る。緑の `󰄲` が起動中、青の `󰄱` が未作成。選ぶだけで作成または切り替えができる。

### detach と exit の違い

| 操作 | 結果 |
|---|---|
| `C-b d`（detach） | **セッションは残る**。後から `C-b C-f` などで戻れる |
| `exit` / `Ctrl + D` | そのペインを終了。最後の1つならセッションも消える |

`Ctrl + D` はシェルの終了で、tmux の機能ではない。誤爆しても zsh の `IGNOREEOF` が効いているので1回では終了しない（`use 'exit' to exit.` と出る）。

**セッションは PC を再起動すると消える。** tmux サーバ（常駐プロセス）が保持しているだけで、ディスクには保存されない。ただし Neovim 側のセッション復元（`<Space>ss`）はディスクに保存されるので、再起動後も開いていたファイルは戻せる。

---

## ウィンドウ

タブのようなもの。画面上部のステータスラインに一覧が出る。

| キー | 動作 |
|---|---|
| `C-b c` | 新規作成 |
| `C-b n` / `C-b p` | 次 / 前へ |
| `C-b 1` `C-b 2` … | 番号で直接移動（**1から始まる**） |
| `C-b w` | 一覧から選ぶ |
| `C-b ,` | 名前を変更 |
| `C-b &` | 閉じる（確認あり） |
| `C-b f` | ウィンドウ名で検索 |

ウィンドウ名は作業ディレクトリ名が自動で入る。

---

## ペイン

ウィンドウ内の画面分割。

### 分割する

| キー | 並び方 |
|---|---|
| `C-b \|` `C-b \` `C-b v` | **左右**に並ぶ（仕切りが縦） |
| `C-b -` `C-b s` | **上下**に並ぶ（仕切りが横） |

`\|` と `-` は文字の形が仕切りの向きと一致する。`v` / `s` は Vim の `<C-w>v` / `<C-w>s` に対応する。`\` は `\|` を Shift 無しで打てるようにしたもの。

### 移動する

| キー | 動作 |
|---|---|
| `C-b h/j/k/l` | 左 / 下 / 上 / 右へ |
| `C-b C-h/C-j/C-k/C-l` | 同上（**Ctrl を離さない**。連続移動可） |
| `C-b o` | 順番に巡回 |
| `C-b q` | 番号を表示して選ぶ |

**`Ctrl` を押したままの方は日本語入力モードでも動く。** 理由は[日本語入力について](#日本語入力について)を参照。

`Alt + hjkl` は**割り当てていない**。skhd が `Alt + j` / `Alt + k` を yabai のウィンドウ操作に使っており、tmux には届かないため。

### 大きさを変える

| キー | 動作 |
|---|---|
| `C-b C-[` / `C-b C-]` | 幅を**狭める** / **広げる**（Ctrl を離さない） |
| `C-b H/J/K/L` | 左 / 下 / 上 / 右へ3ずつ |

どちらも `C-b` を押し直さずに連続で調整できる。`C-b H H H` のように続けて押せばよい。

`C-b H/J/K/L` は日本語入力モードでは効かないので、英数に切り替えてから使う。左右の幅調整は頻度が高いため `C-b C-[` `C-b C-]` を用意してある。こちらは日本語モードでも動く。

### 全画面にする

**`C-b z`** で、フォーカスしているペインをウィンドウ全体に広げる。もう一度押すと元のレイアウトに戻る。分割は保持されるので、閉じたり開き直したりする必要はない。

拡大中はステータスバーのウィンドウ名に `Z` が付く。

### 閉じる

`C-b x`（確認あり）、または `exit`。

## ポップアップ

画面に重ねて起動するツール。閉じると元の画面に戻る。

| キー | 起動するもの |
|---|---|
| `C-b C-g` | lazygit |
| `C-b C-e` | lf（ファイルマネージャ） |
| `C-b C-f` | セッションの作成 / 切り替え |

Neovim の中からも `<Space>gg` で lazygit を開けるが、こちらは tmux のどのペインからでも使える。

## コピーモード

スクロールバックを遡って読んだり、範囲を選んでコピーしたりする。**Vim のキーバインドで操作できる。**

| キー | 動作 |
|---|---|
| `C-b [` | コピーモードに入る |
| `h j k l` `w b` `gg` `G` | Vim と同じ移動 |
| `/` `?` | 検索 |
| `v` | 選択開始 |
| `V` | 行単位で選択 |
| `C-v` | 矩形選択 |
| `y` または `Enter` | コピーして終了（**macOS のクリップボードに入る**） |
| `q` または `Esc` | 終了 |
| `C-b C-p` | 貼り付け |

マウスホイールでもコピーモードに入る。

## 日本語入力について

macOS の日本語入力モードでは、**`C-b` の後に打つキーが IME に食われて tmux に届かない**ことがある。`C-b h` と押しても `h` が「変換待ち」になり、待機時間が過ぎて prefix が解除されてしまう。

### 回避のしかた

**`Ctrl` を離さずに続ける。** `Ctrl` を伴うキーは IME を素通りするため、日本語モードのままでも確実に届く。

| 操作 | 日本語モードでも動く |
|---|---|
| ペイン移動 | `C-b C-h/C-j/C-k/C-l` |
| 左右に分割 | `C-b C-\` |
| 上下に分割 | `C-b C--` |
| 幅を狭める / 広げる | `C-b C-[` / `C-b C-]` |

覚えることは「**`C-b` の `Ctrl` を離さない**」の一点だけ。

### 自動で英数に戻る

ペインの移動・ウィンドウの切り替え・分割の**直後に、IME が自動で英数へ戻る**。`macism` を呼ぶフックを仕込んである。Neovim も同じことを `FocusGained` で行っているため、どちらのペインに移っても日本語モードのまま取り残されることはない。

逆方向（英数 → 日本語）の自動切り替えは行わない。`macism` が日本語への切り替えを受け付けないため、日本語を書く時は手動で切り替える。

### できないこと

**`C-b` を押した時点で英数に戻す、という方法は使えない。** tmux は prefix キーをキーテーブルを引く前に処理するため、`C-b` に処理を挟む割り当てを書いても発火しない。

## 設定の再読み込み

| キー | 動作 |
|---|---|
| `C-b r` | `tmux.conf` を再読み込み |
| `C-b ?` | 全キーバインドの一覧 |

`C-b r` で反映されるのはキーバインドやオプションの変更まで。`default-terminal` のような**新しいペインの生成に関わる設定は既存ペインには効かない**（新しいウィンドウを開けば反映される）。

## よく使う流れ

### 新しいプロジェクトで作業を始める

```
C-b C-f          プロジェクトを選ぶ（無ければ作成される）
nvim .           エディタを開く
C-b |            右にペインを分割
                 → 右で開発サーバやテストを走らせる
C-b C-l          右のペインへ移動
```

### 作業を中断する

```
C-b d            切り離す（セッションは残る）
```

再開するときは `C-b C-f` で同じプロジェクトを選ぶ。Neovim 側も `<Space>ss` でファイルの状態を戻せる。

### 一時的に画面を広く使う

```
C-b z            拡大
（作業）
C-b z            元に戻す
```

## 注意点

**同じセッションに複数の端末から接続しない。** Alacritty と Ghostty のようにサイズの違う端末から同時に繋ぐと、ウィンドウのサイズが交互に変わってペインが伸縮する。`C-b C-f` は接続時に他のクライアントを自動で切り離すので、通常は起きない。

**`C-b` を押した後の入力には制限時間がある。** 既定は500ミリ秒。ゆっくり押すと prefix が解除される。

**Neovim 側のキーマップと衝突しない。** tmux は prefix を押した後のキーだけを横取りするため、Neovim の操作は影響を受けない。prefix 不要で tmux が処理するキーは（マウス操作を除いて）**一つも無い**。

**奪われる修飾キーの組み合わせがある。** tmux に届く前に OS や他のツールが横取りするため、これらは割り当てても機能しない。

| 組み合わせ | 奪う主体 |
|---|---|
| `Ctrl + 矢印` | macOS（デスクトップ切り替え / Mission Control） |
| `Alt + 英字` | skhd（yabai のウィンドウ操作） |
| `Alt + Shift + 英字・記号` | skhd |
| `Cmd` 系 | macOS とアプリ |

**`Ctrl + -` は拡張キープロトコルが前提。** ASCII には `-` に対応する制御文字が存在しないため、従来の方式では送れない。`extended-keys on` を設定して Ghostty から送っている。Alacritty は対応が限定的なので、そちらでは `C-b C--` が効かない（`C-b C-_` または `C-b -` を使う）。
