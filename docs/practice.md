# 操作の練習

読むだけでは指が覚えない。**実際にキーを押して壊しながら覚える**ための教材。

関連: [Vim / Neovim 入門](vim.md)（解説） ／ [tmux](tmux.md) ／ [ウィンドウ操作](window.md)

---

## 始め方

Neovim の中で次を打つ。

```
:Practice
```

一覧が出るので選ぶ。番号を直接指定してもよい。

```
:Practice 03
```

**開かれるのは複製です。** 原本はこのリポジトリに残るので、どれだけ壊してもリポジトリに差分は出ない。初期状態に戻すには `:Practice` をもう一度実行する。

| 操作        | 意味                           |
| ----------- | ------------------------------ |
| `u`         | 1手戻す                        |
| `:Practice` | その教材を初期状態から開き直す |
| `:e!`       | 保存せず開き直す               |

### この設定・プラグイン（07〜08）

**ssh 先では通らない。** 素の形を覚えた上で、打鍵を減らすために足したもの。

|                                          | 内容                     | 主に扱うもの                             |
| ---------------------------------------- | ------------------------ | ---------------------------------------- |
| [07 この設定の操作](practice/07-editor.md) | 素の Vim には無いもの    | `<Space>ff` `Ctrl+h/j/k/l` `]b` `jk`     |
| [08 囲みの操作](practice/08-surround.md) | 囲みを足す・変える・外す | `saiw)` `sr"'` `sd(` `srtt` `sdf` `sh`   |

**上から順にやる。** 02 の `.` が身につく前に 06 の `cgn` へ進んでも効かない。

**07 から先へ先に行かない。** 素の形を知らずに `<Space>ff` だけ覚えると、
サーバー上で手が止まる。07 は各項目に「素の Vim ならどう書くか」を併記してある。

## 進め方

各教材は「課題 → 例のコード → 打鍵 → 確認」の形になっている。

1. 課題を読む
2. **例のコードの上で実際にキーを押す**
3. 想定通りにならなければ `u` で戻してやり直す
4. 分からなければ `<details>` の中の手順を開く

1つの教材は10〜15分ぶん。**全部を一度にやらない。** 1日1つで8日、それを2周する方が身につく。

**01〜06 を2周してから 07 へ行く**のを勧める。素の形が指に入る前に短縮形を
覚えると、ssh 先で何も打てなくなる。
