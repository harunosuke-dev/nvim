# 03 挿入モード — どこから打ち始めるか

> **このファイルは複製です。** やり直すなら `:Practice 03`。
> **ここは全て素の Vim の機能。** ssh 先の `vim` でもそのまま通る。
> この設定で足した抜け方（`jk`）や補完は [07](07-editor.md) にまとめてある。

---

## 1. 入り方を使い分ける

**「移動してから `i`」をやめる。** 入口を選べば1打鍵で済む。

| キー | 由来 | どこから打ち始めるか |
|---|---|---|
| `i` | **i**nsert | カーソルの手前 |
| `a` | **a**ppend | カーソルの次 |
| `I` | | 行の先頭（インデントの後） |
| `A` | | 行の末尾 |
| `o` | **o**pen | 下に新しい行 |
| `O` | | 上に新しい行 |

**課題** — 次の3行それぞれに `;` を足す。行のどこにカーソルがあってもよい。

```
const a = 1
const b = 2
const c = 3
```

`A ; Esc` を1行目でやったら、次の行は `j` `.` で済む。

---

## 2. 抜け方

`Esc` で抜ける。**押しやすい場所に無い**ので、素の Vim では代わりも使える。

| キー | 動作 |
|---|---|
| `Esc` | 標準 |
| `Ctrl+[` | `Esc` と**全く同じ**。ホームポジションから近い |
| `Ctrl+c` | 抜ける（`InsertLeave` の処理を飛ばすので挙動が少し違う） |

**課題** — 下の行に何か打ち込んで、`Ctrl+[` で抜ける。

```
ここに何か打つ →
```

この設定では `jk` でも抜けられるようにしてある。そちらは [07](07-editor.md)。

---

## 3. 挿入モードの中で使えるもの

| キー | 動作 |
|---|---|
| `Ctrl+w` | 直前の**単語**を消す |
| `Ctrl+u` | 行の入力ぶんを消す |
| `Ctrl+r` + レジスタ | レジスタの中身を貼る（`Ctrl+r` `"` で直前のコピー） |
| `Ctrl+o` + コマンド | **1回だけ**ノーマルモードの操作をする |

**課題** — 下の行の末尾に `A` で入り、`Ctrl+w` を2回押して単語を2つ消す。

```
this line has several words at the end
```

## 4. 素の Vim の補完

プラグインが無くても補完はある。**挿入モードで `Ctrl+n` を押すだけ。**
今開いているファイルの中の単語から候補を作る。

| キー | 拾ってくる先 |
|---|---|
| `Ctrl+n` `Ctrl+p` | 次 / 前の候補へ |
| `Ctrl+x` `Ctrl+f` | **ファイル名**（パスを打つ時に効く） |
| `Ctrl+x` `Ctrl+l` | **行ごと**（似た行を丸ごと持ってくる） |
| `Ctrl+e` | 候補を捨てて元に戻す |

**課題** — 下の空行で `configu` まで打って `Ctrl+n` を押す。上の行から
`configuration` が拾われる。

```
const configuration = load()
const
```

**課題** — 新しい行で `const configuration` と打った後、`Ctrl+x` `Ctrl+l` を押す。
1行目がまるごと候補に出る。

この設定では自動でポップアップが出るようにしてある。そちらは [07](07-editor.md)。

## 5. まとめの課題

下の関数に、引数 `options` と1行のコメントを足す。

```lua
local function fetch(url)
  return http.get(url)
end
```

目標:

```lua
-- 取得して返す
local function fetch(url, options)
  return http.get(url, options)
end
```

<details><summary>手順の例</summary>

```
1行目で   O -- 取得して返す Esc      上に行を作る
url の後で f) i , options Esc        括弧の手前に入る
3行目も同様に f) i , options Esc
```

`A` `I` `o` `O` を使い分けると移動がほとんど要らない。

</details>
