# 03 挿入モード — どこから打ち始めるか

> **このファイルは複製です。** やり直すなら `:Practice 03`。

---

## 1. 入り方を使い分ける

**「移動してから `i`」をやめる。** 入口を選べば1打鍵で済む。

| キー | 由来 | どこから打ち始めるか |
|---|---|---|
| `i` | **i**nsert | カーソルの手前 |
| `a` | **a**ppend | カーソルの次 |
| `I` | | 行の先頭（インデントの後） |
| `A` | | 行の末尾 |
| `o` | **o**pen | 下に新しい行 |
| `O` | | 上に新しい行 |

**課題** — 次の3行それぞれに `;` を足す。行のどこにカーソルがあってもよい。

```
const a = 1
const b = 2
const c = 3
```

`A ; Esc` を1行目でやったら、次の行は `j` `.` で済む。

## 2. 抜け方

```
Esc      標準
jk       この設定で足した抜け方
jj       同上
```

`jk` は**ホームポジションから手を動かさずに抜けられる**。下の行に何か打ち込んで、`jk` で抜ける練習をする。

```
ここに何か打つ →
```

**注意** — `j` を1文字だけ打って手を止めると、2文字目を待つ間だけ表示が遅れる。慌てて `k` を押さない。

## 3. 挿入モードの中で使えるもの

| キー | 動作 |
|---|---|
| `Ctrl+w` | 直前の**単語**を消す |
| `Ctrl+u` | 行の入力ぶんを消す |
| `Ctrl+r` + レジスタ | レジスタの中身を貼る（`Ctrl+r` `"` で直前のコピー） |
| `Ctrl+o` + コマンド | **1回だけ**ノーマルモードの操作をする |

**課題** — 下の行の末尾に `A` で入り、`Ctrl+w` を2回押して単語を2つ消す。

```
this line has several words at the end
```

## 4. 補完

この設定では**コードを書くファイルでは自動でポップアップが出る**。文章を書くファイル（markdown / text / gitcommit）では出ない。

| キー | 動作 |
|---|---|
| `Ctrl+n` `Ctrl+p` | 次 / 前の候補へ |
| `Ctrl+j` `Ctrl+k` | 同上 |
| `Tab` | 候補を確定する |
| `Enter` | 確定する（スニペットの穴も進む） |
| `Ctrl+space` | **手動でポップアップを出す** |
| `Ctrl+e` | 閉じる |

**課題** — 下の行の続きに `vim.` と打ち、候補が出たら `Ctrl+n` で動かして `Tab` で確定する。

```lua
local ok = vim.
```

薄く先読みが出る（ゴーストテキスト）。ポップアップを出さなくても `Ctrl+n` で選べる。

## 5. スニペット

`<Space>fs` で一覧から選べる。markdown / mdx では自作のものが入っている。

| キー | 動作 |
|---|---|
| `Tab` | 次の穴へ |
| `Shift+Tab` | 前の穴へ |
| `Enter` | 値を入れて次へ |

## 6. まとめの課題

下の関数に、引数 `options` と1行のコメントを足す。

```lua
local function fetch(url)
  return http.get(url)
end
```

目標:

```lua
-- 取得して返す
local function fetch(url, options)
  return http.get(url, options)
end
```

<details><summary>手順の例</summary>

```
1行目で   O -- 取得して返す Esc      上に行を作る
url の後で f) i , options Esc        括弧の手前に入る
3行目も同様に f) i , options Esc
```

`A` `I` `o` `O` を使い分けると移動がほとんど要らない。

</details>
