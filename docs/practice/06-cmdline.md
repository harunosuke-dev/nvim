# 06 コマンドラインモード — まとめて直す

> **このファイルは複製です。** やり直すなら `:Practice 06`。

---

## 1. 検索

```
apple banana apple cherry apple date
```

| キー | 動作 |
|---|---|
| `/語` + Enter | 前方へ検索 |
| `?語` + Enter | 後方へ検索 |
| `n` `N` | 次 / 前へ |
| `*` | **カーソル下の単語**を検索 |
| `Esc` | ハイライトを消す |

**課題** — `apple` の上で `*` を押す。この設定では**その場に留まる**（標準の Vim は次の出現へ飛ぶ）。`n` で次へ進める。

---

## 2. `cgn` — 1つずつ選びながら直す

**マルチカーソルの代わり。いちばん使う型。**

```
const apple = 1
const apple = 2
const apple = 3
const banana = 4
```

**課題** — `apple` を3つとも `orange` にする。

```
1つ目の apple の上で  *
                      cgn orange Esc
                      n .
                      n .
```

`gn` は「次の一致を選ぶ」テキストオブジェクト。`c` と組み合わせて「次の一致を書き換える」になる。

**課題2** — `u` で戻し、今度は**2つ目だけ飛ばす**。`n` を2回押してから `.` を打つ。

## 3. `:s` でまとめて

```
let count = 0
let count = 1
let count = 2
```

| コマンド | 範囲 |
|---|---|
| `:s/count/total/g` | カーソル行だけ |
| `:%s/count/total/g` | ファイル全体 |
| `:%s/count/total/gc` | 全体、**1つずつ確認**（`y` / `n` / `a` / `q`） |

**課題** — `:%s/count/total/gc` を打ち、`y` と `n` を使い分ける。

`*` で検索してから `:%s//total/g` と**検索語を空にする**と、直前の検索語が使われる。打ち直さずに済む。

---

## 4. `:g` — 条件に合う行だけ

```
TODO: write tests
done: setup project
TODO: fix the bug
done: install deps
TODO: update docs
```

| コマンド | 動作 |
|---|---|
| `:g/TODO/d` | `TODO` を含む行を消す |
| `:v/TODO/d` | `TODO` を含まない行を消す |
| `:g/TODO/normal A !` | 該当行の末尾に ` !` を足す |

**課題** — `:g/done/d` で完了行だけ消す。`u` で戻す。

## 5. 検索結果を一覧にする（quickfix）

**複数のファイルにまたがって直す時の入口。** quickfix は素の Vim の機能で、
`:grep` や `:vimgrep` で一覧を作る。

| コマンド | 動作 |
|---|---|
| `:vimgrep /語/ **/*.md` | 一覧を作る（Vim 内蔵の検索。遅いが確実） |
| `:grep 語 -r .` | 外部の grep を使う（速い） |
| `:copen` `:cclose` | 一覧を開く / 閉じる |
| `:cnext` `:cprev` | 次 / 前の候補へ |
| `:cfdo …` | 一覧に載った**ファイルごと**に実行 |

一覧に送った後は、まとめて置換できる。

```
:cfdo %s/古い語/新しい語/ge | update
```

| 部分 | 意味 |
|---|---|
| `e` | 一致が無いファイルでエラーを出さない |
| `update` | 変更があった時だけ保存 |

**課題** — `:vimgrep /practice/ %` で今のファイルを検索し、`:copen` で一覧を
開く。`:cnext` で行き来してから `:cclose` で閉じる。**置換はしない。**

この設定では `<Space>fg` と `Ctrl+q` で一覧を作れる。そちらは [07](07-editor.md)。

## 6. コマンドラインで使えるもの

| キー | 動作 |
|---|---|
| `Ctrl+r` `Ctrl+w` | **カーソル下の単語**を挿入する |
| `Ctrl+r` `"` | 直前にコピーしたものを挿入する |
| `↑` `↓` | 履歴（打ちかけの文字で絞り込まれる） |
| `q:` | 履歴をバッファとして開く |

**課題** — 下の行の `configuration` の上にカーソルを置き、`:%s/` と打ってから `Ctrl+r` `Ctrl+w` を押す。単語が入る。

```
const configuration = loadConfiguration()
```

## 7. 覚えておくと助かるもの

| コマンド | 動作 |
|---|---|
| `:e!` | 保存せず開き直す（**壊した時の脱出口**） |
| `:w` `:q` `:wq` `:q!` | 保存 / 閉じる / 保存して閉じる / 捨てて閉じる |
| `:noh` | 検索のハイライトを消す（`Esc` でも可） |
| `:help ciw` | 何でも引ける。**一次情報** |

## 8. まとめの課題

下のリストを、`:g` と `:s` だけで整える。

```
- [ ] first task
- [x] second task
- [ ] third task
- [x] fourth task
```

目標: 完了した項目（`[x]`）を消し、残りの `- [ ] ` を `* ` にする。

<details><summary>手順</summary>

```
:g/\[x\]/d
:%s/- \[ \] /* /
```

`\[` は `[` をそのまま扱うための書き方。

</details>
