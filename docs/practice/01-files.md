# 01 ファイルを開く・保存する・終わる

> **このファイルは複製です。** やり直すなら `:Practice 01`。
> **ここは全て素の Vim の機能。** プラグインを1つも使わない。サーバーに入っている
> `vim` でもそのまま同じ手が通る。

---

## 0. 心構え

**ノーマルモードが家。** 迷ったら `Esc`。今どのモードにいるか分からなくなったら、
まず `Esc` を2回押す。

読むだけでは指が覚えない。**このファイルの中で実際にキーを押していく。**

---

## 1. まず脱出口を覚える

壊した時に戻れないと練習にならない。**先にこれだけ覚える。**

| コマンド | 動作 |
|---|---|
| `u` | 1手戻す |
| `:q!` | **保存せずに閉じる。** どうにもならなくなった時の脱出口 |
| `:e!` | 保存せずに開き直す。閉じずにやり直せる |
| `:w` `:q` `:wq` | 保存 / 閉じる / 保存して閉じる |
| `ZZ` | 保存して閉じる（`:` を打たない形） |

このファイルは `~/.local/state/nvim/practice/` の複製で、原本はリポジトリに
残っている。**どれだけ壊してもよい。** `:Practice 01` で初期状態に戻る。

---

## 2. 開く・保存する

| コマンド | 動作 |
|---|---|
| `:e path` | 開く |
| `:e!` | 保存せずに開き直す（**壊した時の脱出口**） |
| `:w` | 保存 |
| `:w path` | **写しを** path へ書く。編集中のファイル名は変わらない |
| `:sav path` | path へ保存し、**以降はそちらを編集する** |
| `:x` | 変更がある時だけ保存して閉じる |

`:w` と `:sav` の違いが要点。`:w backup.md` を打っても、次の `:w` は元のファイルへ
書く。`:sav backup.md` なら次からは `backup.md` へ書く。

**課題** — `:w /tmp/copy.md` を打つ。次に `:f`（ファイル名の表示）で、編集中の
名前が変わっていないことを確かめる。

---

## 3. 新しいファイルを作る

`:e` に無い名前を渡すと、**空のバッファができるだけでファイルはまだ無い。**
`:w` して初めてディスクに現れる。

**課題** — 順に打つ。

```
:e memo.txt
i こんにちは<Esc>
:w
:ls
```

`:ls` に `memo.txt` が並ぶ。

無いディレクトリの下には書けない。`:w` が `E212` で断る。

**課題** — 失敗を1度見ておく。

```
:e sub/deep/note.txt
:w
```

素の Vim での直し方はこれ。**ディレクトリを作ってから書く。**

```
:!mkdir -p %:h
:w
```

`%:h` は「今のファイルの置き場」。次の節で扱う。

---

## 4. ファイル名を打たない

`%` は編集中のファイル名。後ろに付ける記号で削れる。

| 書き方 | `docs/practice/01-files.md` の場合 |
|---|---|
| `%` | `docs/practice/01-files.md` |
| `%:h` | `docs/practice` — **h**ead、置き場 |
| `%:t` | `01-files.md` — **t**ail、名前だけ |
| `%:r` | `docs/practice/01-files` — **r**oot、拡張子を落とす |
| `%:e` | `md` — **e**xtension |
| `%:p` | `/Users/…/01-files.md` — 絶対パス |

繋げられる。`%:t:r` で `01-files`。

**課題** — 打って結果を見る。`:echo` は表示するだけで何も壊さない。

```
:echo %:t
:echo %:h
:echo %:t:r
```

**課題** — 隣に同じ拡張子のファイルを作る。手で打つのは名前の一部だけ。

```
:e %:h/scratch.%:e
:w
```

---

## 5. バッファを行き来する

開いたファイルは**バッファ**として残る。閉じたつもりでも残っている。

| コマンド | 動作 |
|---|---|
| `:ls` | 一覧。左の数字がバッファ番号 |
| `:b 3` | 3番へ |
| `:b memo` | **名前の一部**で選べる。番号を覚えなくてよい |
| `Ctrl+^` | **直前のバッファと往復**。これが一番速い |
| `:bd` | 今のバッファを閉じる |
| `:bn` `:bp` | 次 / 前 |

**課題** — `:e memo.txt` → `Ctrl+^` → `Ctrl+^` と打つ。2つのファイルを行き来する。
**`:b` を打つより速い。**

`:ls` の右に出る記号は `%`（今いる）、`#`（`Ctrl+^` の相手）、`+`（未保存）。

---

## 6. 範囲を指定する

`:` の後ろに範囲を書くと、その行だけに効く。

| 書き方 | 範囲 |
|---|---|
| `:%` | ファイル全体 |
| `:.` | 今の行 |
| `:$` | 最終行 |
| `:1,5` | 1行目から5行目 |
| `:.,+3` | 今の行から3行下まで |
| `:'<,'>` | 直前に選んだ範囲（ビジュアルから `:` を打つと自動で入る） |
| `:/TODO/` | 次に `TODO` がある行 |

**課題** — 下のリストで試す。毎回 `u` で戻す。

```
banana
apple
cherry
date
apple
```

```
:.,+2d          今の行から3行消す
:1,3sort        1〜3行目だけ並べ替える
:%sort u        全体を並べ替えて重複を消す
```

`:normal` を混ぜると、範囲の各行にノーマルモードの操作を流せる。

**課題** — 全ての行の末尾に `,` を付ける。

```
:%normal A,
```

---

## 7. 外のコマンドと繋ぐ

| 書き方 | 動作 |
|---|---|
| `:!cmd` | 実行して結果を見せるだけ。バッファは変わらない |
| `:r !cmd` | 実行結果を**カーソルの下に読み込む** |
| `:r file` | ファイルの中身を読み込む |
| `:.!cmd` | **今の行を** cmd に通して置き換える |
| `:%!cmd` | **ファイル全体を**通して置き換える |

**課題** — 下の行の上にカーソルを置き、`:.!tr a-z A-Z` を打つ。行が大文字になる。

```
convert this line to upper case
```

`u` で戻す。次に `:r !date` を打つ。日付が下の行に入る。

**この形が効くのは整形。** JSON を `:%!jq .` で整える、行を `:%!sort -u` で
並べ替える、といった使い方をする。**外のコマンドをそのまま呼べる。**

---

## 8. 元いた場所へ戻る

大きなファイルで迷子になった時に効く。

| キー | 戻る先 |
|---|---|
| `` `. `` | **最後に変更した場所** |
| `''` | 直前のジャンプの前にいた行 |
| `` `" `` | そのファイルを前回閉じた時の場所 |
| `Ctrl+o` | ジャンプの履歴を**戻る** |
| `Ctrl+i` | 履歴を**進む** |

**課題** — `G` で最終行へ飛び、`Ctrl+o` で戻る。次に適当な行を `x` で1文字消し、
`G` で飛んでから `` `. `` で消した場所へ戻る。

`:marks` で今持っている印の一覧が出る。

---

## 9. 画面を分ける

素の Vim の画面分割は全て `Ctrl+w` から始まる。**どのサーバーでも同じ。**

| キー | 動作 |
|---|---|
| `Ctrl+w` `v` | 縦に分ける（左右に並ぶ） |
| `Ctrl+w` `s` | 横に分ける（上下に並ぶ） |
| `Ctrl+w` `h` `j` `k` `l` | 左 / 下 / 上 / 右の画面へ移る |
| `Ctrl+w` `q` | 今の画面を閉じる |
| `Ctrl+w` `o` | **他を全部閉じる**（only） |

**課題** — `Ctrl+w` `v` で分け、右の画面で `:e memo.txt` を開く。`Ctrl+w` `h` で
左へ戻り、`Ctrl+w` `o` で1画面にする。

---

## 10. コマンドラインそのものを編集する

`q:` を打つと、**コマンドの履歴がバッファとして開く。** 普通の Vim の操作で
編集でき、`Enter` でその行を実行する。長いコマンドを打ち直さずに直せる。

閉じるのは `Ctrl+c` か `:q`。

**課題** — `q:` を開き、`k` で前のコマンドまで戻り、一部を直して `Enter`。

---

## 11. まとめの課題

下の内容から `list.txt` を作り、整えて保存する。**プラグインを使わない。**

```
cherry
banana
apple
banana
```

目標: 上の4行だけを含む `list.txt` を作り、重複を消して並べ替え、
各行の先頭に `- ` を付ける。

<details><summary>手順</summary>

```
4行をビジュアル行選択（V で選んで j で伸ばす）して y
:e %:h/list.txt
p
:1d
:%sort u
:%normal I-
:w
```

`:1d` は `p` で残る先頭の空行を消すため。`:%sort u` の `u` が重複を落とす。
`:%normal I-` は各行の先頭に挿入する。**`-` の後ろの空白まで入れるなら
`:%normal I- ` と末尾に空白を打つ。**

</details>
