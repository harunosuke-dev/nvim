# 01 基本操作 — 開く・分ける・移る

> **このファイルは複製です。** 好きなだけ壊してよい。
> `u` で1手戻る。最初からやり直すなら `:Practice`。
> 課題は上から順に。答えは各課題の一番下にある。

---

## 0. 心構え

**ノーマルモードが家。** 迷ったら `Esc`。今どのモードにいるか分からなくなったら、まず `Esc` を2回押す。

このファイルの中で実際にキーを押していく。読むだけでは指が覚えない。

---

## 1. ファイルを探して開く

いま開いているのは練習用の複製で、原本は設定リポジトリの中にある。**原本を探して開いてみる。**

```
<Space>ff       ファイル検索を開く
practice        と打って絞り込む
Ctrl+n / Ctrl+p 候補を上下に動かす
Enter           開く
```

開いたら `Ctrl+o` でここへ戻ってくる。

<details><summary>うまくいかない時</summary>

- 候補が出ない → `<Space>` を押してから `f` `f` を続けて押す。押しっぱなしにしない
- 閉じたい → `Esc`
- 戻れない → `<Space>fb` でバッファ一覧から選ぶ

</details>

---

## 2. 画面を分ける

```
<Space>\        縦に分ける（左右に並ぶ）
<Space>-        横に分ける（上下に並ぶ）
```

**両方試す。** 3〜4個に分けてよい。分けたら次へ。

---

## 3. 分けた画面を移る

```
Ctrl+h   左へ      Ctrl+l   右へ
Ctrl+j   下へ      Ctrl+k   上へ
```

移った先の色が変わることを確認する。**いま作業していない画面は少し明るく沈み、カーソル行の帯も消える。** どこにいるか一目で分かるようにしてある。

---

## 4. 画面を閉じる

```
Ctrl+w q     いまの画面を閉じる
Ctrl+w o     他を全部閉じる（only）
```

`Ctrl+w o` で1画面に戻す。

---

## 5. バッファを渡り歩く

Vim では「開いたファイル」がバッファとして残る。画面を閉じてもバッファは消えない。

```
Shift+h     前のバッファへ
Shift+l     次のバッファへ
<Space>fb   一覧から選ぶ
<Space>bd   いまのバッファを閉じる
```

課題1で原本を開いていれば、`Shift+h` と `Shift+l` で行き来できる。

---

## 6. 保存と終了

```
<Space>w    保存
<Space>q    閉じる
:wq         保存して閉じる
:q!         保存せず閉じる
```

**`:q!` は覚えておく。** どうにもならなくなった時の脱出口。

---

## 7. まとめの課題

次を続けてやる。

1. `<Space>\` で縦に分ける
2. 右の画面で `<Space>ff` → `README` を開く
3. `Ctrl+h` で左へ戻る
4. `Ctrl+w o` で1画面にする
5. `<Space>fb` でバッファ一覧を出し、この練習ファイルへ戻る
