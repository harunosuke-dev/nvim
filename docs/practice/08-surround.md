# 08 囲みの操作 — 覚えると書き換えが速くなるプラグイン

> **このファイルは複製です。** やり直すなら `:Practice 08`。
> **ここだけプラグインが要る**（mini.surround）。ssh 先の素の `vim` では通らない。
> 素の Vim での代わりは最後の節に置いてある。

---

## 1. 3つの語を覚えるだけ

`"hello"` を `'hello'` に変える。素の Vim だと囲みの片方ずつ相手をする。

```
f"x  f"x  i'<Esc>  ...
```

mini.surround なら **`sr"'` の4打鍵で終わる。** 囲みを1つのまとまりとして
扱えるようになる。**この1点だけで入れる価値がある。**

覚えるのは前置の `s`（**s**urround）と、その次に来る動詞だけ。

| | 由来 | すること |
|---|---|---|
| `sa` | **a**dd | 囲みを**足す** |
| `sr` | **r**eplace | 囲みを**入れ替える** |
| `sd` | **d**elete | 囲みを**外す** |
| `sf` | **f**ind | 囲みの端へ**飛ぶ** |
| `sh` | **h**ighlight | 囲みを**光らせる** |

**素の Vim の `s`（1文字消して挿入）は消えていない。** 単独で押すと
`timeoutlen`（この設定では 150ms）待ってから動く。急ぐなら `cl` が同じ動作。

---

## 2. `sd` — 外す（一番わかりやすい）

`sd` の後ろに**外したい囲みの記号**を打つ。

```javascript
const message = "hello";
const items = [1, 2, 3];
const wrapped = compute(value);
```

**課題** — 1つずつ試す。毎回 `u` で戻す。**カーソルは囲みの中ならどこでもよい。**

```
"hello" の中で sd"          → hello
[1, 2, 3] の中で sd[        → 1, 2, 3
compute(value) の中で sd)   → computevalue
```

記号をまとめて指すエイリアスもある。**どの引用符か思い出せなくてよい。**

| | 指すもの |
|---|---|
| `q` | `'` `"` `` ` `` のどれでも |
| `b` | `)` `]` `}` のどれでも |
| `f` | 関数呼び出し |
| `t` | HTML タグ |

**課題** — `sdq` を打つ。`"hello"` でも `'hello'` でも同じ1打鍵で外れる。

---

## 3. `sr` — 入れ替える

`sr` の後ろに **今の囲み** → **新しい囲み** の順で2つ打つ。

```javascript
const greeting = "hello";
const call = compute(value);
```

**課題** — 順に打つ。1周して元に戻る。

| キー | 結果 |
|---|---|
| `sr"'` | `"hello"` → `'hello'` |
| `sr'` + `` ` `` | `'hello'` → `` `hello` `` |
| ``sr` "`` | `` `hello` `` → `"hello"` |

括弧同士も入れ替わる。`compute(value)` の中で `sr)]` を打つと
`compute[value]` になる。**`srqb` なら「引用符が何であれ括弧にする」。**

---

## 4. `sa` — 足す（的を指定する）

`sa` だけは**どこを囲むか**を渡す必要がある。テキストオブジェクト（05）が
そのまま使える。

| キー | すること |
|---|---|
| `saiw)` | **単語**を `()` で囲む |
| `saiW"` | 空白まで含めた塊を囲む |
| `sai(]` | 括弧の**中身**を `[]` で囲む |
| `sa$"` | カーソルから行末までを囲む |

```javascript
hello world
name
```

**課題** — `hello` の上で `saiw)` を打つ。`(hello) world` になる。

ビジュアルで選んでから `sa` も打てる。**範囲が変則的で言い表せない時に使う。**

**課題** — `viw` で単語を選び、`sa]` を打つ。`[hello]` になる。

---

## 5. 開き括弧と閉じ括弧は違う

**ここが最初に引っかかるところ。**

| キー | 結果 |
|---|---|
| `saiw)` | `(hello)` — **空白なし** |
| `saiw(` | `( hello )` — **内側に空白が入る** |

**閉じ括弧が「詰める」、開き括弧が「空ける」。** `{}` `[]` も同じ。
迷ったら**閉じ括弧側**を打てばよい。

**課題** — 同じ単語で `saiw)` と `saiw(` を打ち比べる。毎回 `u` で戻す。

---

## 6. 離れた囲みを狙う — `n` と `l`

**ここが mini 系の効き所。** `sd` `sr` の後ろに `n`（next）または `l`（last）を
挟むと、**カーソルを動かさずに次の／前の囲みを対象にできる。**

```javascript
aa "bb" cc
(aa) bb (cc)
```

| キー | 対象 |
|---|---|
| `srnq)` | **次の**引用符を `()` に変える → `aa (bb) cc` |
| `sdl)` | **前の**括弧を外す |
| `2sd)` | **2つ外側**の括弧を外す（**カウントは `sd` の前**） |

**課題** — 1行目の先頭で `srnq)` を打つ。`f"` で移動してから `sr"` を打つのと
同じことが1手で済む。

**カウントの位置に注意。** `sd2)` は動かない。`2sd)` と前に置く。

`sa` の側は的をテキストオブジェクトで渡すので、**mini.ai の `in(` `inq` が
そのまま使える**（`sain()` で次の括弧の中を囲む）。

---

## 7. タグ — `t` を打ってから名前を聞かれる

```html
hello world <em>emphasis</em>
```

**課題** — `hello` の上で `saiwt` を打つ。`Tag:` と聞かれるので `em` と打って
`Enter`。`<em>hello</em>` になる。

| キー | すること |
|---|---|
| `saiwt` → `em` `Enter` | 単語を `<em>` で囲む |
| `srtt` → `strong` `Enter` | 今のタグを `<strong>` に変える（`t` を2回） |
| `sdt` | タグを外して中身だけ残す |

**`srtt` の `t` が2つ**なのは「今の囲み = タグ」「新しい囲み = タグ」だから。
`srt)` と打てばタグが括弧になる。

**属性ごと打ってもよい。** `saiwt` → `div class="box"` `Enter` で
`<div class="box">hello</div>`。閉じタグには名前だけが入る。

---

## 8. 関数呼び出し — `f`

```javascript
value;
console.log(result);
```

**課題** — `value` の上で `saiwf` を打ち、`String` と打って `Enter`。
`String(value)` になる。

| キー | すること |
|---|---|
| `saiwf` → `String` `Enter` | `value` → `String(value)` |
| `srff` → `warn` `Enter` | `console.log(x)` → `warn(x)` |
| `sdf` | `console.log(x)` → `x` |

**`sdf` は「この関数呼び出しを剥がす」。** デバッグの `console.log()` を
外す時にそのまま効く。

## 9. 探す・光らせる

| キー | すること |
|---|---|
| `sf)` | 囲みの**閉じ**側へ飛ぶ |
| `sF)` | 囲みの**開き**側へ飛ぶ |
| `sh)` | 囲みの両端を**一瞬光らせる** |

**課題** — `sh)` を打って、どこが対象になっているかを目で確かめる。
外す前に確認したい時に使う。

素の Vim の `%`（対応する括弧へ飛ぶ）と近いが、`sf` は**中にいる状態から
外側の囲みへ**飛べる。`%` は括弧の上にいる必要がある。

## 10. 素の Vim ではどうするか

ssh 先にこのプラグインは無い。**同じことを標準機能でやる形も知っておく。**

| したいこと | mini.surround | 素の Vim |
|---|---|---|
| `"hello"` → `'hello'` | `sr"'` | `ci"` で取り直すか `f"r'` を2回 |
| `"hello"` → `hello` | `sd"` | `di"` して `hi`、または `f"x` を2回 |
| 単語を `"` で囲む | `saiw"` | `ciw` → `"` → `Ctrl+r` `"` → `"` → `Esc` |
| 囲みの端へ飛ぶ | `sf)` | `%`（括弧の上にいる時）、`])` `[(` |

`Ctrl+r` `"` は挿入モードで**直前に消したもの**を貼る書き方。`ciw` で単語を消して
挿入モードに入り、`"` を打ち、消した単語を貼り、`"` を打つ。

**打鍵数が3倍になる。** これがプラグインを入れる理由そのもの。

## 11. `ys` から来た人へ

以前は nvim-surround（vim-surround 互換の `ys` / `cs` / `ds`）を使っていた。
**`ys` の `y` は「**y**ou surround」の語呂で、yank とは無関係。** 読み違えやすい
ので mini.surround へ移した。対応は次の通り。

| 旧（vim-surround 系） | 今 |
|---|---|
| `ysiw)` | `saiw)` |
| `yss)` | `sa$)`（行末まで）／ `V` して `sa)` |
| `cs"'` | `sr"'` |
| `ds"` | `sd"` |
| ビジュアルの `S)` | ビジュアルの `sa)` |
| `cst` | `srtt` |
| `dsf` | `sdf` |

**動詞の位置が逆になった**と考えると移りやすい。`ys`+的 →
`sa`+的、`cs`+旧+新 → `sr`+旧+新。

## 12. まとめの課題

下のコードを、囲みの操作だけで直す。

```javascript
const label = "user name";
const node = <span>text</span>;
console.log(payload);
```

目標:

1. `"user name"` を `` ` `` （テンプレートリテラル）に変える
2. `<span>` を `<strong>` に変える
3. `console.log(payload)` から呼び出しを外して `payload` だけにする
4. 残った `payload` を `String()` で包む

<details><summary>手順</summary>

```
1行目の user name の中で   sr"`
2行目の text の中で        srtt → strong Enter
3行目の payload の中で     sdf
そのまま payload の上で    saiwf → String Enter
```

`sdf` の後、カーソルは `payload` の上に残るのでそのまま `saiwf` へ続けられる。

</details>
