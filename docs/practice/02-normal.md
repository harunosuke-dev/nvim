# 02 ノーマルモード — 動詞 + 移動

> **このファイルは複製です。** 実際に消したり書き換えたりして練習する。
> `u` で1手戻る。やり直すなら `:Practice 02`。

---

## 1. 移動だけで動く

下の行の中で、**キー1つでどこまで飛べるか**を試す。

```
const userName = getUserProfile(userId, { includeAvatar: true })
```

| キー | 動き |
|---|---|
| `w` `b` | 次 / 前の語の先頭へ |
| `e` | 語の末尾へ |
| `0` `^` `$` | 行頭 / 最初の文字 / 行末 |
| `f(` | 次の `(` へ |
| `t,` | 次の `,` の**手前**へ |
| `;` | 直前の `f` `t` を繰り返す |
| `%` | 対応する括弧へ |

**課題** — 行頭から `f{` を押し、そこで `%` を押す。閉じ括弧へ飛べば正解。

この設定では `w` `e` `b` が **camelCase の区切りでも止まる**。`getUserProfile` の上で `w` を連打して確かめる。

---

## 2. 動詞と組み合わせる

**動詞 + 移動**で範囲が決まる。下の行で試す。

```
const message = "hello world, this is a test"
```

| 打鍵 | 起きること |
|---|---|
| `dw` | 語を1つ消す |
| `d$` | 行末まで消す |
| `dt,` | カンマの手前まで消す |
| `ct)` | `)` の手前まで書き換える |
| `y$` `p` | 行末までコピーして貼る |

**1つ試すたびに `u` で戻す。** 元に戻ることを確認しながら進める。

---

## 3. 行ごと扱う

```
local first = 1
local second = 2
local third = 3
```

| 打鍵 | 起きること |
|---|---|
| `dd` | 1行消す（切り取り） |
| `yy` `p` | 1行コピーして下に貼る |
| `dd` `p` | **行を移動する** |
| `3dd` | 3行まとめて消す |

**課題** — `second` の行を `third` の下へ移す。`dd` してから `j` して `p`。

---

## 4. `.` で繰り返す

**Vim でいちばん強力なキー。** 直前の操作をもう一度やる。

```
let alpha = 0
let beta = 0
let gamma = 0
```

**課題** — `let` を `const` に3行とも変える。

```
1行目の let の上で  cw const Esc
j で次の行へ、l などで let の上へ  →  .
もう一度                            →  .
```

打ち直さずに `.` だけで済むことを体感する。

---

## 5. 数を付ける

ほとんどの操作に回数を付けられる。

```
one two three four five six seven eight
```

| 打鍵 | 起きること |
|---|---|
| `3w` | 3語進む |
| `d3w` | 3語ぶん消す |
| `2f e` | 2つ目の `e` へ（スペース不要、`2fe`） |

---

## 6. 取り消しとやり直し

```
u        取り消す
Ctrl+r   やり直す
U        その行への変更をまとめて取り消す
```

さんざん壊した後、`u` を連打して元に戻してみる。**どこまで戻れるか**を知っておくと怖くなくなる。

---

## 7. まとめの課題

下のコードを、`u` を使わずに次の形へ書き換える。

```
function calculate(a, b) {
  return a + b
}
```

目標:

```
function calculate(x, y) {
  return x * y
}
```

<details><summary>手順の例</summary>

```
1行目の a の上で  cw x Esc
w などで b へ移り  cw y Esc
2行目へ移り        cw x Esc      （return の次の a）
+ の上で           r *
最後の b で        cw y Esc
```

`cw` を4回打つより、`*` で検索して `cgn` を使う手もある。それは [06 コマンドライン](06-cmdline.md) で扱う。

</details>
