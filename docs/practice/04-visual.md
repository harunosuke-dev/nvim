# 04 ビジュアルモード — 選んでから決める

## 1. 3種類の選び方

| キー | 選び方 |
|---|---|
| `v` | **文字**単位 |
| `V` | **行**単位 |
| `Ctrl+v` | **矩形**（列で選ぶ） |

選んだ後は動詞を押す。`d` で消す、`y` でコピー、`c` で書き換え、`>` でインデント。

**課題** — 下の行を `V` で選び、`>` を押してインデントを1段深くする。`<` で戻す。

```
const value = 1
```

## 2. 選択を広げる

選んでいる最中も移動キーがそのまま使える。

```
function example(first, second, third) {
  return first + second
}
```

**課題** — `first` の上で `v` を押し、`f)` を押す。`)` まで一気に広がる。

`o` を押すと**選択の反対側へカーソルが移る**。左に伸ばし直したい時に使う。

---

## 3. 行を動かす

この設定では、選んだ行を丸ごと上下に動かせる。

```
step three
step one
step two
```

| キー | 動作 |
|---|---|
| `J`（ビジュアル中） | 選択行を下へ |
| `K`（ビジュアル中） | 選択行を上へ |

**課題** — 上の3行を `one` `two` `three` の順に並べ替える。

---

## 4. 矩形選択（マルチカーソルの代わり）

**同じ列を一度に編集する。**

```
alpha
beta
gamma
delta
```

**課題** — 4行すべての先頭に `- ` を足す。

```
alpha の行頭で  Ctrl+v
jjj             下へ3行伸ばす
I               先頭に挿入
- （スペース）
Esc             ← ここで全行に反映される
```

**`Esc` を押すまで1行目にしか見えない。** 慌てない。

末尾に足すなら `A`。行の長さが違っても `$` で行末まで選べる。

**課題2** — 上の4行の末尾に `,` を足す。`Ctrl+v` `jjj` `$` `A` `,` `Esc`。

## 5. 選んだ範囲だけ置換

```
old one
old two
old three
```

**課題** — 上の3行だけ `old` を `new` にする。

```
V jj          3行選ぶ
:             コマンドラインに '<,'> が入る
s/old/new/g
Enter
```

ファイル全体ではなく**選んだ範囲だけ**が対象になる。

---

## 6. 選び直す

| キー | 動作 |
|---|---|
| `gv` | **直前の選択を復元する** |
| `gV` | 同上（自動選択を無視） |

`>` でインデントすると選択が外れるが、`gv` `>` を繰り返せば続けて深くできる。

## 7. まとめの課題

下の表を、矩形選択だけで整える。

```
name  | type
id    | number
title | string
```

目標: 各行の先頭に `| ` を足し、末尾に ` |` を足す。

<details><summary>手順</summary>

```
1行目の行頭で  Ctrl+v jj I | （スペース） Esc
1行目の行頭で  Ctrl+v jj $ A （スペース） | Esc
```

</details>
