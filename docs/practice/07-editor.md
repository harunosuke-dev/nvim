# 07 この設定ならではの操作 — 素の Vim には無いもの

> **このファイルは複製です。** やり直すなら `:Practice 07`。
> **ここから先は ssh 先の `vim` では通らない。** 01〜06 で覚えた素の操作の上に、
> この設定で足したものだけを積む。**素の形を先に覚えてから来ること。**

---

## 1. 何が足してあるか

素の Vim でも同じことはできる。**打鍵数と目の動きが減るだけ。**
だからこそ、素の形を知らずにここから入ると、サーバー上で手が止まる。

| したいこと | 素の Vim（01〜06） | この設定 |
|---|---|---|
| ファイルを開く | `:e path` | `<Space>ff` で絞り込む |
| 全文検索 | `:vimgrep` | `<Space>fg` |
| 画面を分ける | `Ctrl+w` `v` | `<Space>wv` |
| 画面を移る | `Ctrl+w` `h` | `Ctrl+h` |
| バッファを移る | `:b name` | `]b` `[b` `<Space>fb` |
| 挿入モードを抜ける | `Esc` `Ctrl+[` | `jk` |
| 行を上下に動かす | `:'<,'>m'>+1` | ビジュアル中の `J` `K` |

## 2. ファイルを探して開く

いま開いているのは練習用の複製で、原本は設定リポジトリの中にある。
**原本を探して開いてみる。**

```
<Space>ff       ファイル検索を開く
practice        と打って絞り込む
Ctrl+n / Ctrl+p 候補を上下に動かす
Enter           開く
```

開いたら `Ctrl+o` でここへ戻ってくる。**`Ctrl+o` は素の Vim の機能**（01 の
ジャンプリスト）なので、こちらは ssh 先でも同じ。

<details><summary>うまくいかない時</summary>

- 候補が出ない → `<Space>` を押してから `f` `f` を続けて押す。押しっぱなしにしない
- 閉じたい → `Esc`
- 戻れない → `<Space>fb` でバッファ一覧から選ぶ

</details>

**探す範囲を広げる**キーも用意してある。

| キー | 範囲 |
|---|---|
| `<Space>ff` | いまいるディレクトリ配下 |
| `<Space>fF` | **ホーム配下**（設定ファイルを探す時） |
| `<Space>fr` | 最近開いたファイル |
| `<Space>fp` | プロジェクトを選んで移動する |

## 3. 画面とバッファ

```
<Space>wv       縦に分ける
<Space>ws       横に分ける
Ctrl+h / Ctrl+l 左 / 右の画面へ
Ctrl+j / Ctrl+k 下 / 上の画面へ
```

**`Ctrl+w` を挟まずに移れる**のがここの効き所。分けた画面を行き来する回数は
1日で何十回にもなる。

移った先の色が変わることを確認する。**いま作業していない画面は少し明るく沈み、
カーソル行の帯も消える。**

バッファの移動も同じ理屈で短くしてある。

| キー | 動作 | 素の形 |
|---|---|---|
| `]b` `[b` | 次 / 前のバッファ | `:bn` `:bp` |
| `<Space>fb` | 一覧から選ぶ | `:ls` → `:b 3` |
| `<Space>bd` | 今のバッファを閉じる | `:bd` |

**課題** — `<Space>wv` で分け、右で `<Space>ff` → `README` を開く。`Ctrl+h` で
左へ戻り、`Ctrl+w` `o` で1画面にする（`Ctrl+w` `o` は素の Vim のまま）。

## 4. 挿入モードの抜け方と補完

`jk` と `jj` で抜けられる。**ホームポジションから手を動かさずに済む。**

```
ここに何か打つ →
```

**注意** — `j` を1文字だけ打って手を止めると、2文字目を待つ間だけ表示が遅れる。
慌てて `k` を押さない。

補完は**コードを書くファイルでは自動でポップアップが出る**。文章を書くファイル
（markdown / text / gitcommit）では出ない。

| キー | 動作 |
|---|---|
| `Ctrl+n` `Ctrl+p` | 次 / 前の候補へ |
| `Ctrl+j` `Ctrl+k` | 同上 |
| `Tab` | 候補を確定する |
| `Enter` | 確定する（スニペットの穴も進む） |
| `Ctrl+space` | **手動でポップアップを出す** |
| `Ctrl+e` | 閉じる |

**課題** — 下の行の続きに `vim.` と打ち、候補が出たら `Ctrl+n` で動かして
`Tab` で確定する。

```lua
local ok = vim.
```

薄く先読みが出る（ゴーストテキスト）。ポップアップを出さなくても `Ctrl+n` で選べる。

**スニペット**は `<Space>fs` で一覧から選べる。markdown / mdx では自作のものが
入っている。`Tab` で次の穴、`Shift+Tab` で前の穴。

## 5. 行を上下に動かす

ビジュアルで選んで `J` `K`。**素の Vim の `:'<,'>m'>+1` を1打鍵にしたもの。**

```
step three
step one
step two
```

**課題** — 上の3行を `one` `two` `three` の順に並べ替える。

選択が保たれたまま動くので、`J` を連打して位置を決められる。

## 6. 全文検索と quickfix

```
<Space>fg     全文検索
Ctrl+q        候補を全部 quickfix へ送る
]q  [q        次 / 前の候補へ
<Space>uq     一覧を開閉
```

素の `:vimgrep` と違い、**打ちながら結果が絞り込まれる。** 送った後の
`:cfdo` は素の Vim と同じ（06 を参照）。

**課題** — `<Space>fg` で `practice` と検索し、`Ctrl+q` で quickfix に送る。
`]q` `[q` で行き来してから `<Space>uq` で閉じる。**置換はしない。**

## 7. テキストオブジェクトを増やす

05 で覚えた `di{` `ci"` の**単位を増やす**プラグインが入っている。
考え方は全く同じで、`i` / `a` の後ろに来る文字が増えるだけ。

### 引数（mini.ai）

```typescript
function send(url: string, body: object, retries: number) {}
```

| キー | 範囲 |
|---|---|
| `dia` | 引数1つ（**a**rgument） |
| `daa` | 引数1つ + カンマ |
| `cia` | 引数の中身を書き換える |

**課題** — `body` の上で `daa`。カンマごと消えて、残りが
`(url: string, retries: number)` になれば正解。

**素の Vim なら** `di(` で全部消すか、`f,` で区切りへ飛んで `dt,` のように
手で範囲を作る。**引数1つを単位として言い表せない。**

### 関数（treesitter）

```lua
local function helper(x)
  return x * 2
end

local function main()
  return helper(21)
end
```

| キー | 範囲 |
|---|---|
| `dif` | 関数の中身（**f**unction） |
| `daf` | 関数ごと |
| `vaf` | 関数を選ぶ |

**課題** — `helper` の中で `daf`。関数が丸ごと消える。`u` で戻して `dif`。
中身だけ消える。

**素の Vim なら** `V` で目視して選ぶか、`d/^end` のように検索で終端を指す。
**構文を理解していないので「関数」という単位が無い。**

## 8. ファイラ（oil.nvim）

`<Space>e` でディレクトリが**編集できるバッファとして**開く。

| 操作 | すること |
|---|---|
| 行を書き換える | ファイル名を変える |
| 行を消す | 削除する（ゴミ箱へ行くので戻せる） |
| 行を足す | 新規作成。末尾が `/` ならディレクトリ |
| `:w` | **ここで初めて確定する** |
| `-` | 親ディレクトリへ |

**普通の Vim の操作がそのまま使える**のが要点。`dd` で消して `p` で貼れば移動、
`cw` で名前を直せる。左端に git の状態（`M` 変更 / `A` 追加 / `?` 未追跡）が出る。

**課題** — `<Space>e` で開き、`-` で親へ上がり、`Enter` で降りる。**書き換えない。**

素の Vim では `:Ex`（netrw）が同じ位置にあるが、操作感は全く違う。

## 9. まとめの課題

**素の形とこの設定の形を、同じ作業で打ち比べる。**

1. `<Space>ff` で `README` を開く → `Ctrl+^` で戻る（素）
2. `<Space>wv` で分ける → `Ctrl+w` `o` で戻す（素）
3. `<Space>fg` で `practice` を検索 → `Esc` で閉じる
4. 同じ検索を `:vimgrep /practice/ %` と `:copen` でやる（素）

**3 と 4 の差が、このファイルの存在理由。** 4 は ssh 先でも打てる。
